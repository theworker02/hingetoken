# hingetoken

Hinge structured JSON token payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/hingetoken/

## Install / run

```bash
git clone https://github.com/theworker02/hingetoken.git
cd hingetoken
node src/cli.js
node --test
```
